# Bet365 Scraper & Live Odds

### 🚀 Quick Start (1-Click)

1. Double-click **`start_chrome_cdp.bat`**
   - Automatically launches Google Chrome and scrapes all sports directly into `all_matches.json`.

2. Double-click **`start_odds_display.bat`** (or open `index.html`)
   - Opens the live odds dashboard in your browser.

---

### 📋 First-Time Setup
- **Google Chrome** installed
- Run once in terminal:
  ```bash
  pip install -r requirements.txt
  ```

---

### 📁 Output
- All scraped matches and odds are saved to **`all_matches.json`**.
